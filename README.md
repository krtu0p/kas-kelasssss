# 🚀 Laravel + React Starter Kit

Selamat datang di **Laravel + React Starter Kit**! 🎉  
Proyek ini adalah titik awal sempurna bagi kamu yang ingin menggabungkan kekuatan **Laravel (untuk backend API)** dan **React (untuk frontend SPA)** dalam satu project yang terintegrasi.

> Dibuat dengan semangat produktivitas dan efisiensi 💖 agar kamu bisa langsung mulai coding tanpa harus setup semuanya dari nol.

---

## 📦 Fitur Unggulan

- ✅ Laravel 11+ sebagai backend API powerful
- 🔐 Autentikasi SPA menggunakan Laravel Sanctum
- ⚛️ React + Vite (super cepat & ringan)
- 🧭 React Router DOM untuk navigasi antar halaman
- 🎨 Tailwind CSS untuk styling modern
- 📡 Axios untuk HTTP request
- 🧪 Laravel Feature & Unit testing (default)
- 🔄 Opsional: React Query untuk fetching data
- 💻 Hot reload untuk frontend dan backend
- 🚀 Siap di-deploy ke server production
